A lexer, parser, and tree-abstract-er for y86 instructional language (from _Computer Systems: A Programmer's Perspective_ by Bryant and O'Hallaron).

Built as a learning exercise, based on CPSC 311 and 313.

Parsing based on reference provided by UBC in [reference PDF](./y86reference.pdf), with the following extensions:
- `.quad`, `.pos`, etc. --- assembler directives are ignored

Code based on instructional material by Paulette Koronkevich and Ron Garcia (from CPSC 311).
Program samples from instructional material in CPSC 313.
